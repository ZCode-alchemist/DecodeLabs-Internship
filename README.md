### Project 2 - Iris Flower Classification

A machine learning classification project that uses the Iris dataset to classify flowers into different species based on their features.

**Features:**

* Iris dataset classification
* Data preprocessing
* Feature scaling
* Machine learning classification
* Model evaluation
* Classification report
* Confusion matrix visualization
* Example prediction

**Technologies:**

* Python
* Scikit-learn
* Pandas
* Matplotlib
* Seaborn

---

### Project 3 - Movie Recommendation System

A Python-based movie recommendation system that recommends movies based on the user's preferred genres.

**Features:**

* User genre preferences
* Genre-based movie matching
* Similarity score calculation
* Percentage match calculation
* Top 3 movie recommendations
* Handles cases where no matching movies are found

**Technologies:**

* Python
* Lists and Dictionaries
* Functions
* Sets
* Basic Recommendation Logic

**Example:**

If the user enters:

```text
Action, Sci-Fi
```

the system compares these preferences with the genres of available movies and displays the movies with the highest matching percentage.
